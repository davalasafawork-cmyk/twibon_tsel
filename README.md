# 🎨 Twibbon Editor untuk Profil WhatsApp (1080x1080)

Website statis interaktif berbasis HTML5 Canvas untuk memasang foto ke bingkai Twibbon dengan ukuran pas untuk profil WhatsApp (1:1 / 1080x1080 px).

## ✨ Fitur:
- **Upload Twibbon Sendiri**: Unggah bingkai format PNG transparan ukuran 1080x1080 px.
- **Upload Foto**: Unggah foto selfie / profil Anda (JPG, PNG, WebP).
- **Interaksi Geser & Atur**: Geser foto (drag), zoom in/out, rotasi, dan flip agar posisinya pas di dalam lubang Twibbon.
- **Preview WhatsApp**: Pas untuk dipasang sebagai avatar/foto profil WhatsApp.
- **Download Langsung**: Unduh hasil foto beresolusi tinggi 1080x1080 px format PNG tanpa kompresi.
- **Bisa Digunakan Publik**: Dibuat sebagai web statis murni sehingga dapat langsung di-host gratis di **GitHub Pages**.

## 🚀 Cara Pasang ke GitHub Pages (Gratis & Publik)
1. Buat repository baru di GitHub (misal: `twibbon-profil-wa`).
2. Masuk ke menu **Settings** > **Pages** di repository GitHub Anda.
3. Pada bagian **Build and deployment** -> **Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
4. Website Anda akan langsung aktif dan bisa diakses publik oleh siapa saja (misal: `https://<username>.github.io/<repo-name>/`).
